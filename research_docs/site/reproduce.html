Files and how to reproduce

Commands

# Part B (your Brooks work)
make test-100k forrester plot        # 100k MC + Forrester + plots
make all-modified                    # architectures

# Part C (lawkit)
make laws                            # evidence cards (~4 min)
make evidence REPOS=<dir with helix/ and aider/ clones>
make sensitivity
make lawkit-test

# this site
python research_docs/build.py
python -m http.server 8765 -d research_docs/site

Clones (read-only): git clone https://github.com/apache/helix, git clone https://github.com/Aider-AI/aider. On Windows, add -c http.sslBackend=schannel if you hit SSL certificate errors.
