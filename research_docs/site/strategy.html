D4. A generic framework for future SE laws (goal 2)

Implemented as lawkit/. A new law is one Law(...) spec plus, optionally, one miner. Each run extracts reusable knowledge:

  1. A model-defect catalogue, checked automatically: dead parameters, hard-coded channels, clamp-made verdicts, outflow overshoot, an outcome that isn't the law's words, an antecedent false by default.
  2. Dimensionless thresholds that travel between projects: V*, the aiwork inequality, archpat break-even.
  3. A measurement agenda (VOI), phrased as tool + column.
  4. Price the lever first. Every "doing L improves/hurts Y" law is a claim about the sign of (benefit − price of L). Ask whether the price is in the model (if not, the claim is a tautology, as in archpat) and in any data (if not, it is undecidable, as in aiwork).
  5. Composition. resources.txt sketches chaining Brooks → aiwork → archpat. The specs are designed so a combined model is just another Law (not built yet).
