A1. Purpose

This is a methodology paper for ICSE 2027 (NIER first, then EMSE) by Menzies and Kazman with Umar, with Carlos on tooling. The framing is "what to measure next: model-based triage for SE empirical research". The project doesn't collect new data. It triages which data are worth collecting by building small simulations of SE laws and checking which of their parameters can be "lifted" from existing open-source data.

A3. How a "law" is represented

Every law is a function in paper/sd.py returning Model(init, step, y, rq, ctrl):

  • init: {name: [default, lo, hi, unit]}. UPPER-case names are inputs (state of the world), lower-case names are parameters (the process).
  • step(dt, t, u, v): one Euler step of the stocks and flows.
  • y(trajectory): the success measure (higher = better).
  • rq(): the research question. Run the model with the control variable ctrl at two values and compare y, giving CONFIRM / REFUTE / neutral (5%-of-y0 threshold).
