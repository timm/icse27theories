The 8-project family

All 8 are mature Apache- or Apache-adjacent open-source projects with long git history, accessible issue trackers, and stable identity records. They were chosen for language diversity, age range, and team size spread — not for any prior expectation about the V&V outcome.

Five binaries do the heavy lifting. Each is called from the kaiaulu R package; the tools.yml file at the repo root tells kaiaulu where to find each binary on disk.

Per-project data dictionary

Every project has a conf/<project>.yml that defines where its raw data lives on disk and how to extract structured CSVs. A typical entry: 

project:
  website: https://helix.apache.org

repository:
  git: /opt/data/helix.git
  vcs: git

mailing_list:
  mbox: /opt/data/helix-dev.mbox

issue_tracker:
  jira:
    domain: issues.apache.org
    project_key: HELIX
    issue_jsons: /opt/data/helix_jira/

analysis:
  cveps:
    - identity_id        # kaiaulu identity_match output column
    - file_pathname      # gitlog file column

The conf file is the contract between the project's raw data and the parsers. Once it is filled out for a project, every lift in the bank is in principle runnable on that project.

Anonymity note

This site is configured for double-blind submission. The 8 project names are public Apache projects whose data is itself public. No team-internal data is used; no contributor name appears on this site except as found in public git history. The hyperlinks above point to the canonical repos hosted by Apache / GitHub.

Source links on every model page point to github.com/timm/icse27theories — a placeholder location for the working copy. A double-blind mirror will be set up for submission, and the scripts/link_sd_refs.py module's GH_BASE constant gets the anonymous URL swapped in pre-build.

Reproducibility

Each lift is an .Rmd notebook in lifts/ with a companion .R for reusable helpers. Carlos's convention. The notebooks run end-to-end given the project's conf/<project>.yml and the 5 binaries installed. Failures are documented in kaiaulu_notes/known_bugs.md.

Total reproducibility cost from a clean machine:

  • ~2 hours: install R + CRAN packages + kaiaulu
  • ~1 hour: install Perceval, Depends, scc, RefactoringMiner, pattern4, PyDriller
  • ~6 hours: clone the 8 git repos + pull issue-tracker dumps
  • ~20 hours: run all lifts end-to-end (most projects, most models)
