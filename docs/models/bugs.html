Goel, A. L. & Okumoto, K. (1979). Time-dependent error-detection rate model.

What this model says

Software-reliability-growth: cumulative defects discovered N(t) follows an exponential approach to an asymptote a. The discovery rate b decays as Latent bugs are removed from the system.

Success measure (model.y)

Cumulative Fixed at the end of the run.

Conjecture (model.rq)

Doubling initial Latent stock approximately doubles eventual Fixed (linearity of recovery process).

The SD model

From models/sd.py:

def bugs():
  """Goel-Okumoto [2]: exponential reliability growth.
  RQ: 2x initial Latent -> ~2x eventual Fixed (linearity of recovery)."""
  init = {'Latent':[100,0,200], 'Found':[0,0,200], 'Fixed':[0,0,200],
          'find_rate':[0.15,0.01,0.5], 'fix_rate':[0.5,0.05,1]}

  def step(dt, t, u, v):
    find = u.Latent * u.find_rate
    fix  = u.Found  * u.fix_rate
    v.Latent = u.Latent - dt * find
    v.Found  = u.Found  + dt * (find - fix)
    v.Fixed  = u.Fixed  + dt * fix
    v.find_rate, v.fix_rate = u.find_rate, u.fix_rate

  def y(out):
    """Mid-curve recovery (t=10 of 20): tests scaling, not asymptote.
    Asymptote is always ~1.0 by construction (exponential decay)."""
    mid_idx = len(out) // 2
    return out[mid_idx][1].Fixed

  def rq(bg=None):
    bi = init if bg is None else bg
    return verdict("2x initial Latent -> ~2x mid-curve Fixed",
                   y(run({**bi, 'Latent':[ 50,0,200]}, step)),
                   y(run({**bi, 'Latent':[100,0,200]}, step)), 'up')

  return Model(init, step, y, rq, 'Latent')

rm(list = ls())
seed <- 1
set.seed(seed)
require(kaiaulu); require(data.table); require(stringi)
require(knitr); require(yaml); require(jsonlite)
source("functions.R")
gh_issue_glob <- "/Users/timm/Downloads/helix/github/apache_helix/issue/*.json"
files <- Sys.glob(gh_issue_glob)
cat("Issue files:", length(files), "\n")

issues <- rbindlist(lapply(files, function(f) {
  d <- fromJSON(f, simplifyVector = FALSE)
  if (is.list(d) && !is.null(d[[1]]$id)) {
    # list of issues
    rbindlist(lapply(d, function(i) {
      labels <- vapply(i$labels %||% list(), `[[`, "", "name")
      data.table(
        id        = as.integer(i$id %||% NA),
        state     = i$state %||% NA_character_,
        labels    = paste(labels, collapse = ";"),
        closed_at = i$closed_at %||% NA_character_
      )
    }), fill = TRUE)
  } else if (is.list(d) && "issues" %in% names(d)) {
    rbindlist(lapply(d$issues, function(i) data.table(
      id = as.integer(i$id %||% NA),
      state = i$state %||% NA_character_,
      labels = "",
      closed_at = i$closed_at %||% NA_character_
    )), fill = TRUE)
  } else NULL
}), fill = TRUE)

cat("Total issues parsed:", nrow(issues), "\n")
cat("States:\n"); print(table(issues$state))
bugs <- issues[grepl("bug", labels, ignore.case = TRUE) &
               !is.na(closed_at) & closed_at != ""]
cat("Bug-labeled + closed:", nrow(bugs), "\n")
bugs[, closed_ts := as.POSIXct(closed_at, format = "%Y-%m-%dT%H:%M:%SZ",
                               tz = "UTC")]
setorder(bugs, closed_ts)
t0       <- min(bugs$closed_ts)
rel_t    <- as.numeric(difftime(bugs$closed_ts, t0, units = "secs"))
cum_N    <- seq_along(rel_t)
mean_N   <- mean(cum_N)
ss_tot   <- sum((cum_N - mean_N)^2)
a_max    <- max(cum_N) * 1.2
best     <- list(a = NA, b = NA, sse = Inf)
for (a in a_max * c(0.8, 1.0, 1.2, 1.5, 2.0, 3.0)) {
  for (b in c(1e-9, 1e-8, 1e-7, 1e-6, 1e-5, 1e-4)) {
    pred <- a * (1 - exp(-b * rel_t))
    sse  <- sum((pred - cum_N)^2)
    if (sse < best$sse) best <- list(a = a, b = b, sse = sse)
  }
}
r2 <- 1 - best$sse / ss_tot
cat(sprintf("Goel-Okumoto: a=%.2f  b=%.3e  R^2=%.4f\n",
            best$a, best$b, r2))
span_days <- as.numeric(difftime(max(bugs$closed_ts), t0, units = "days"))
cat(sprintf("Span: %.1f days\n", span_days))
dir.create("../outputs", showWarnings = FALSE)
out <- data.table(
  project         = "helix",
  n_issues_total  = nrow(issues),
  n_bugs_closed   = nrow(bugs),
  gokumoto_a      = best$a,
  gokumoto_b      = best$b,
  fit_r2          = r2,
  span_days       = span_days,
  seed            = seed
)
fwrite(out, "../outputs/lift_bugs_helix.csv")
kable(out)

What we learned

Lifted on 3 projects with bug-classification data: Helix (170 GH-bug-label closed, a=245, R²=0.62), kaiaulu (22 closed, a=26, R²=0.91), camel (185 JIRA-Bug-type resolved, a=178, R²=0.60). All three are in the early-discovery regime — none have saturated, so the linearity claim cannot be falsified yet.
