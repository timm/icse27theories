# Archive: Brooks results before the single standard model (2026-11-06)

Four Brooks models existed before this date: `brooks` (sd.brooks, score at
t=20), `brooks_late` (sd.brooks, finish time of a late project),
`brooks_fixed` and `brooks_late_fixed` (extended: five literature
structures, bounded overload, dt 0.125). From 2026-11-06 lawkit keeps one
standard model, `brooks` = the former `brooks_late_fixed`, and the Brooks
miner fits the same bounded-overload formula.

Contents: the four models' evidence cards (`laws/`), the Forrester report
over all four (`forrester_all.*`), the straight-line-formula Helix/Aider
estimates (`evidence/brooks_late_*.json`), and the sensitivity and
synthesis files as they stood.
