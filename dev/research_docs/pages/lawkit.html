C1. The lawkit framework

lawkit/ makes the Part B testing generic. It works on any paper/sd.py model and produces the same evidence card for each law. About 750 lines in total, including specs and tests; the miners add about 440.

The data places a project in the law's regime map. It doesn't estimate an average "Brooks effect". That is Cartwright's distinction between "it worked there" and "it will work here" (D).

C1.7 Adding a new law

from lawkit.core import Law
import sd
DEBT = Law("debt", sd.debt, "starting with Debt=50 slows delivery",
           lever="Debt", arms=(0, 50), expect="down",
           factors=["born_rate", "pay_rate", "intr_rate"],
           channels={"intr_rate": 0})
# add to LAWS in lawkit/laws.py, then:  python run_laws.py debt

Run on the untouched sd.debt, the battery immediately reports a knock-out FAIL (its main channel is the hard-coded speed = 1 − Debt/100) and a refutability WARN (100% CONFIRM). These are the same defect types archpat has.
