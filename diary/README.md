# diary/ — notable prompts + emails archive

Place for prompts, emails, and prompt-relevant artifacts worth
sharing with collaborators (Carlos, Rick, Umar) but not part of the
code repository.

## Conventions

- One file per item.
- Naming: `YYYY-MM-DD_<short-slug>.md`.
- Emails: paste verbatim with sender + date in a blockquote.
- Prompts: paste the prompt as the body; if Claude's response was
  used to seed work in the repo, link to the resulting commits.

## Index

- `2026-05-20_carlos_email.md` — Carlos's email re: 6 datasets, sanity
  checks, .Rmd format request, tool URLs, view-mode question. Filed
  during the 2026-05-24 Claude Code session.

## Why diary, not NOTES.md?

`NOTES.md` is Tim's personal session diary. `diary/` is a shared
correspondence archive — prompts, emails, decision points — that
collaborators can review without poking around in personal notes.

`findings.md`, `TIMETABLE.md`, and source code are the authoritative
artifacts; `diary/` is the conversation history that produced them.
